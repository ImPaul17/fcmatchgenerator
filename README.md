# FC Match Generator

Una aplicación web interactiva para generar enfrentamientos aleatorios entre equipos de fútbol para FC25.

<img src="logo%20trans.png" alt="FC Match Generator Logo" width="400"/>

## 📋 Descripción

FC Match Generator es una herramienta web que permite generar enfrentamientos aleatorios entre equipos de fútbol. La aplicación incluye equipos de las principales ligas europeas Y selecciones internacionales, permitiendo a los usuarios personalizar qué equipos desean incluir en la generación de partidos.

## 🎮 Cómo Usar

1. Abre la aplicación en tu navegador.
2. Haz clic en el botón "GENERAR PARTIDO" para crear un enfrentamiento aleatorio.
3. Para personalizar los equipos disponibles, haz clic en el botón de personalización (⚙️) en la esquina superior derecha.
4. Selecciona o deselecciona los equipos que deseas incluir en la generación de partidos.
5. Guarda tus preferencias y disfruta de la aplicación personalizada.

## 🖥️ Compatibilidad

- **Navegadores**: Compatible con todos los navegadores modernos (Chrome, Firefox, Safari, Edge, Opera, Brave, etc.)
- **Dispositivos móviles**: La aplicación funciona mejor en dispositivos móviles cuando se activa la opción "Vista de ordenador" o "Vista de escritorio" en el navegador del dispositivo.
