# FC Match Generator

Una aplicación web interactiva para generar enfrentamientos aleatorios entre equipos de fútbol de las principales ligas europeas.

<img src="logo%20cuadrado.png" alt="FC Match Generator Logo" width="400"/>

## 📋 Descripción

FC Match Generator es una herramienta web que permite generar enfrentamientos aleatorios entre equipos de fútbol. La aplicación incluye equipos de las principales ligas europeas como La Liga, Premier League, Serie A, Bundesliga y Ligue 1, permitiendo a los usuarios personalizar qué equipos desean incluir en la generación de partidos.

## ✨ Características

- **Generación aleatoria de partidos**: Crea enfrentamientos aleatorios entre equipos de fútbol con una animación visual atractiva.
- **Personalización de equipos**: Selecciona qué equipos quieres incluir en la generación de partidos.
- **Filtros por ligas**: Incluye equipos de las principales ligas europeas:
  - La Liga (España)
  - Liga Hypermotion (España)
  - Premier League (Inglaterra)
  - Serie A (Italia)
  - Bundesliga (Alemania)
  - Ligue 1 (Francia)
- **Efectos de sonido**: Incluye efectos sonoros para mejorar la experiencia del usuario.
- **Diseño responsive**: Adaptado para funcionar en dispositivos móviles y de escritorio.
- **Interfaz intuitiva**: Diseño moderno y fácil de usar con animaciones fluidas.

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura de la aplicación
- **CSS3**: Estilos y animaciones
- **JavaScript**: Lógica de la aplicación

## 📥 Instalación

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en tu navegador.

## 🎮 Cómo Usar

1. Abre la aplicación en tu navegador.
2. Haz clic en el botón "GENERAR PARTIDO" para crear un enfrentamiento aleatorio.
3. Para personalizar los equipos disponibles, haz clic en el botón de personalización (⚙️) en la esquina superior derecha.
4. Selecciona o deselecciona los equipos que deseas incluir en la generación de partidos.
5. Guarda tus preferencias y disfruta de la aplicación personalizada.

## 🔊 Control de Sonido

- Puedes ajustar el volumen o silenciar los efectos de sonido utilizando el control de volumen en la esquina superior derecha.

## 🖥️ Compatibilidad

- **Navegadores**: Compatible con todos los navegadores modernos (Chrome, Firefox, Safari, Edge, Opera, Brave, etc.)
- **Dispositivos móviles**: La aplicación funciona mejor en dispositivos móviles cuando se activa la opción "Vista de ordenador" o "Vista de escritorio" en el navegador del dispositivo.
